# Release qualification

This checklist describes work still required; checking local code is not provider acceptance.

- Run the 20-request live compiler corpus and report executable preservation and expected clarification as separate denominators. Inspect every output for unsupported additions and relevant clarification; an unexpected clarification is not executable success.
- On the exact release commit: three consecutive valid captures, three variant denials with provider-confirmed void, and three shipping denials with provider-confirmed void. Record 9/9 or the actual denominator and failures, never extrapolated percentages.
- Recover from a blocked attempt with the identical contract hash, a new attempt/order/authorization, fresh buyer approval, and one completed $148 capture. A second recovery is rejected.
- Exercise duplicate concurrent approval/recovery commands, worker restart at financial boundaries, interrupted capture responses, duplicate/out-of-order webhooks, and invalid signatures. Verify actual resource retrieval, one merchant order per protected purchase, and no unresolved authorization.
- Run the isolated operator-only Sandbox payment control once. It pairs real payment readback with a local M-to-S fixture mutation; it creates no Northpath cart or merchant order. Keep that limitation visible and separate from protected execution. Do not claim a demonstrated wrong-size purchase without implementing and verifying a real controlled-merchant order.
- Export reviewed redacted evidence, record source HEAD and deployed revision, and ensure the public library actually opens without a session or credentials.
- Verify 390/768/1440 layouts, keyboard flow, focus visibility, dialog focus, reduced motion, error messages and readable status labels.
- Check every submission URL while signed out. Check final YouTube video visibility and duration independently. Confirm authenticated Devpost submission/finalization and timestamp; keep a redacted receipt. A project page alone is not proof of submission.
- Keep deployment, source, video and evidence available through December 21, 2026. Use a paid non-expiring database within the approved budget; verify the dashboard quote before creating resources.
